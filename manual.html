Setup & Launch Guide

1 Set Environment Variables

Set your Google Gemini API key and specify your TurtleBot model.

export GEMINI_API_KEY="your_api_key_here"
export TURTLEBOT3_MODEL="burger"

2 Launch TurtleBot Bringup

Bring up the physical robot or Gazebo simulation environment.

ros2 launch turtlebot3_bringup robot.launch.py

3 Start the AI Companion Controller Node

Execute the main intent parsing and safety controller.

ros2 run companion_ai voice_intent_controller

Supported Intent Formats

The Gemini reasoning layer parses user speech into validated JSON structures:

Movement Intent

"Move forward a bit and check the room"

{
  "intent": "NAVIGATE_RELATIVE",
  "parameters": {
    "linear_x": 0.2,
    "duration_sec": 3.0
  },
  "confidence": 0.98
}
Companion/Dialogue Intent

"Remind me to take my medicine in 10 minutes"

{
  "intent": "SET_REMINDER",
  "parameters": {
    "reminder_text": "Take medicine",
    "timer_minutes": 10
  },
  "confidence": 0.95
}

Safety Rules & Diagnostic Checks

LiDAR Distance Threshold

If obstacles are detected within 0.25 meters, velocity overrides automatically publish 0.0 m/s.

Command Timeout Fallback

Twist signals auto-expire after 200ms without fresh validated heartbeat pulses.
